# مغامرة زكي — Zaki's Adventure 🎮

لعبة منصّات كلاسيكية بستايل ألعاب الـ NES القديمة، تشتغل من المتصفح على الكمبيوتر والموبايل، وتتثبت كبرنامج (PWA) وتشتغل بدون إنترنت.

**▶ العب الآن:** https://merofarahat923-coder.github.io/zaki-adventure/

- 8 مراحل في عالمين (سهول، كهف، سما الغروب، قلعة الحمم، تلال الثلج، البحر، غابة الليل، حصن الملك)
- زعيمان، سباحة، أرض جليدية، نجمة حماية، كرات نار، مخابئ سرية ونقاط حفظ
- تحكم بالكيبورد أو أزرار لمس على الموبايل
